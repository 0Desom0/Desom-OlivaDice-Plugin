# DwarfJokes 矮人笑话插件说明

## 1. 做了什么

这是一个 OlivOS 轻量插件，用来在群聊/私聊里抽取、新增、删除全局矮人笑话，并提供桌面 GUI 和 WebUI。

已经落地的能力：

- 四个主命令别名：`矮人笑话` / `dwarfjokes` / `矮人` / `dwarf`
- 默认前缀：`.` `。` `/` `／`
- 全部子命令用模板 `utils.parse_command` 做**贪婪匹配**，不按空格切第一词。`.矮人add正文`、`.矮人adminadd10086` 都能识别
- 全局合集文件名固定为 `DwarfJokesPack.json`
- 新增笑话只写 `text`，`category` / `platform` / `source_url` / `note` / `original_en` 留空
- 序号优先填补空缺，再继续自增
- 重复度使用 OlivaDiceCore 帮助文档的 `getRecommendRank` 算法打分，分数 **低于 50** 判定为重复，并告诉你撞上了哪个序号
- `add` / `del` 需要 OlivaDiceCore 骰主、本插件骰主或本插件管理员
- `admin add/del` 需要 OlivaDiceCore 骰主或本插件骰主
- `list` / `show` / `展示` 不带序号时回报合集数量；带序号则展示指定笑话
- 未命中主命令、或主命令后既不是子命令也不是纯数字时，**不回复**
- 桌面菜单和 WebUI 都能管开关、骰主、管理员和笑话合集

初始 819 条笑话从 `D:\Backup\Downloads\矮人笑话合集\DwarfJokesPack.json` 搬运到插件种子目录。OlivOS 第一次启动时，如果运行时合集还不存在，会把这份种子复制到数据目录。

## 2. 为什么用轻量插件模板

| 模板 | 适用 |
| --- | --- |
| 官方原生模板 | 功能很少、没有复杂存储/GUI |
| **轻量插件模板** | 多命令、配置、GUI、WebUI、可选用 OlivaDiceCore |
| 规则集模板 | 强依赖人物卡 / 规则检定 |

这个插件要 GUI + WebUI + 全局 JSON 存储 + 可选 OlivaDiceCore 权限/打分，所以选轻量模板。没有 OlivaDiceCore 时插件仍能跑，重复度会用插件内的同款算法回退。

源模板来自本仓库 `示例/LightPluginTemplate/YourPluginName/`。

## 4. 插件运行时生成的目录

数据**不写在插件源码目录**，统一写到 OlivOS 工作目录下的 `plugin/data/DwarfJokes/`，避免 `.opk` 解包到 `plugin/tmp` 时把用户数据冲掉。

```text
plugin/data/DwarfJokes/
├── DwarfJokesPack.json          # 全局笑话合集（所有 Bot 共用）
├── global_config.json           # 全局启用 / 调试开关
├── <raw_bot_hash>/
│   └── bot_config.json          # Bot 开关、骰主、管理员、群禁用列表
└── <linked_bot_hash>/
    ├── message_custom.json      # 自定义回复词（跟随 OlivaDiceCore 群链）
    ├── message_variable.json
    └── storage/
```

首次启动时：

1. 模板 `initialize_plugin` 为每个 Bot 建好配置目录
2. 若 `plugin/data/DwarfJokes/DwarfJokesPack.json` 不存在，从 `DwarfJokes/Data/DwarfJokesPack.json` 复制种子
3. 之后所有增删都只改运行时这份 JSON，不会回写种子文件

`bot_config.json` 默认结构：

```json
{
  "bot_enable_switch": true,
  "configured_master_list": [],
  "configured_admin_list": [],
  "disabled_group_list": []
}
```

笑话条目结构：

```json
{
  "id": 1,
  "text": "笑话正文",
  "original_en": "",
  "category": "",
  "platform": "",
  "source_url": "",
  "note": ""
}
```

命令新增时后五个字段都是空字符串。种子合集里已有条目会保留原来的分类和来源。

## 5. 命令一览

前缀默认 `.` `。` `/` `／`。下面只写 `.矮人`，另外三个主命令别名行为相同。

| 命令 | 行为 |
| --- | --- |
| `.矮人` | 随机抽 1 条 |
| `.矮人10` / `.矮人 10` | 抽 N 条。N>10 按 10，N<1 按 1 |
| `.矮人add 正文` / `.矮人 添加 正文` | 新增。成功会回序号和当前总数 |
| `.矮人del 序号` / `.矮人rm序号` / `.矮人 删除 序号` | 删除该序号 |
| `.矮人list` / `.矮人show` / `.矮人 展示` | 当前共有多少条、下一个填补序号 |
| `.矮人list5` / `.矮人show 5` / `.矮人 展示 5` | 展示指定序号的笑话。序号非法或不存在会提示 |
| `.矮人帮助` / `.矮人 help` | 帮助 |
| `.矮人admin add 用户ID` | 添加本插件管理员 |
| `.矮人admin del 用户ID` | 删除本插件管理员 |
| `.矮人 咖啡` 或 `.别的命令` | 不回复 |

抽选同一轮内不重复。合集不足 N 条时有多少抽多少。

## 6. 权限

| 操作 | OlivaDiceCore 骰主 | 本插件骰主 `configured_master_list` | 本插件管理员 `configured_admin_list` |
| --- | --- | --- | --- |
| 抽选 / list / help | 不需要 | 不需要 | 不需要 |
| add / del 笑话 | 可以 | 可以 | 可以 |
| admin add/del | 可以 | 可以 | 不可以 |

没有 OlivaDiceCore 时，Core 骰主判定为否，只认本插件骰主/管理员。

## 7. 重复度怎么打分

打分函数与 `OlivaDiceCore.helpDoc.getRecommendRank` 一致：

- 越低越像
- `0`：完全相同、一方是另一方子串，或几乎覆盖整句的近义改写
- 算法内部若认为不像，会把分数加上 `1000`

Core 帮助文档把 **rank < 1000** 当作“值得推荐”，但那是给短词条用的，而且还会丢掉长度 ≥ 25 的键。矮人笑话普遍含“矮人”，不同笑话打出来也经常是 100～600。如果照搬 1000，几乎没法新增。

本插件仍用同一套分数，判定门槛改为：

**rank < 50 视为重复**

实测：

- 原文 / 子串 / 只改一两个字：0～4
- 另一条不同的矮人笑话：通常 > 100
- 完全无关的英文：> 1000

有 Core 时直接调用 `OlivaDiceCore.helpDoc.getRecommendRank`；没有时用 `function.get_local_recommend_rank` 回退。重复时回复会带上撞到的序号和分数。

## 8. GUI 和 WebUI

桌面菜单「打开插件配置」对应 `DwarfJokes_Menu_001`。

三个页签：

1. 全局设置：启用开关、调试开关
2. Bot 配置：当前 Bot 开关、回复词、骰主、管理员
3. 笑话合集：数量、下一个填补序号、浏览/新增/删除/随机抽一条

WebUI 入口在 OlivOS 侧栏「插件页面」→「矮人笑话配置」。必须从已登录的宿主侧栏打开，页面不能自己 `fetch` 核心 API。网页事件名：`DwarfJokes_WebUI_Config`。

WebUI 不会把 819 条正文一次性塞进回包，只传合集摘要；新增、删除、抽选走独立 action。

## 9. 部署与检查

1. 复制 `娱乐/DwarfJokes/` 到 OlivOS 的 `plugin/app/DwarfJokes/`
2. 确认 `app.json` 是 UTF-8 无 BOM，文件开头应是 `{`（字节 `7B`），不能是 `EF BB BF`
3. 重载插件
4. 看日志是否出现 `DwarfJokes init 完成`
5. 确认生成了 `plugin/data/DwarfJokes/DwarfJokesPack.json`
6. 发 `.矮人帮助`、`.矮人`、`.矮人list`、`.矮人list1` 做冒烟
7. 需要 GUI 时点菜单；需要网页时从 WebUI 侧栏进入

依赖：

- 必需：OlivOS（`compatible_svn` 190+）
- 可选：OlivaDiceCore（骰主判定、群 on/off、参考度函数）
- GUI 需要 Tkinter。`gui.py` 在插件加载时导入，因为 OPK 解包目录随后会被 OlivOS 删除；没有 Tkinter 时菜单会提示改用 WebUI，并把真实导入异常写进日志

本机已跑过：

```text
python -m unittest discover -s 娱乐/DwarfJokes/tests -v
```

```text
python -m flake8 --config 娱乐/DwarfJokes/.flake8 娱乐/DwarfJokes --exclude=__pycache__,Data
```

无报错。`app.json` 开头字节为 `7b`，无 BOM。
