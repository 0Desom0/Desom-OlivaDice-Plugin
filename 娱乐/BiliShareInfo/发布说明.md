### 说明

BiliShareInfo 是一个 B 站分享解析插件，用于在群聊中自动识别并展示哔哩哔哩视频和直播间信息。

#### 主要功能

- 自动识别群聊中的 B 站视频链接
- 支持识别 BV 号、AV 号
- 支持识别 b23.tv 和 bili2233.cn 短链接
- 支持识别 QQ 小程序形式的哔哩哔哩分享
- 支持识别 `live.bilibili.com` 直播间链接
- 直播间解析可展示封面、主播、状态、公告、分区、标签、关注、在线人数和开播时间
- 支持一条消息内解析多个 B 站视频或直播间
- 支持单条/多条结果使用合并转发展示
- 支持群聊单独开启或关闭普通视频解析
- 支持群聊单独开启或关闭直播解析
- 支持全局开启或关闭全部解析
- 支持设置未单独配置群聊的普通视频默认解析状态
- 可选使用预览图 OCR 识别 UP 主和播放/弹幕/点赞数据
- OCR 与标题搜索并行执行，对最多 20 个候选逐条评分
- 同名标题优先按 UP 主和统计数据核验，评分并列时随机选择
- 避免将 QQ 图片 URL 查询参数中的随机 `av数字` 误判为 AV 号
- 引用消息只解析用户本次输入的内容，不解析被引用消息中的卡片或链接

#### 指令

- `.bili help` 查看帮助
- `.bili on/off` 开启/关闭本群普通视频解析
- `.bili live on/off` 开启/关闭本群直播解析
- `.bili global on/off` 开启/关闭全局解析
- `.bili default on/off` 设置未配置群聊的普通视频默认解析状态
- `.bili singleforward on/off` 设置单条结果是否使用合并转发
- `.bili multiforward on/off` 设置多条结果是否使用合并转发
- `.bili ocr on/off` 开启/关闭预览图 OCR 增强匹配
- `.bili debug on/off` 开启/关闭解析调试日志

#### 默认状态

- 全局解析默认开启
- 未单独配置群聊时，普通视频解析默认开启
- 未单独配置群聊时，直播解析默认开启
- 本群普通视频解析和本群直播解析彼此独立
- 关闭全局解析后，普通视频和直播解析都会停止
- 已经通过指令显式设置过的群会保留自己的开关状态

#### 可选依赖

预览图增强匹配使用轻量的 `rapidocr_onnxruntime`。未安装时会自动跳过 OCR，并回退到标题搜索。

OCR 依赖仅在源码运行环境中安装后生效：

```text
pip install rapidocr_onnxruntime "numpy<2.0" "opencv-python<5"
```

OCR 只在卡片带有 QQ 预览图时运行，不影响普通 BV/AV 链接和直播间链接解析。OCR 与标题搜索结果不一致时，插件会综合比较候选视频的完整标题、UP 主、播放、弹幕和点赞数据。识别出 UP 主后，会优先通过 B 站的 UP 主关键词投稿接口查找视频，并对同名投稿补充详情后再评分。

直播解析使用 B 站直播房间公开接口。本群直播开关独立于普通视频的本群开关，但全局开关关闭时不会触发。

#### 权限说明

- 本群普通视频开关可由群主、管理员、骰主操作
- 本群直播开关可由群主、管理员、骰主操作
- 全局开关、默认开关、合并转发、OCR 和调试日志设置仅骰主可操作
