## 简介

用于管理 QQ 官方机器人的：

- **自定义菜单**：只出现在消息列表单聊底部，最多 10 项。
- **指令面板**：输入 `/` 或 `@机器人` 拉起，支持消息列表 / QQ 群 / QQ 频道 / 频道私信四个场景。

主要能力：

- 本地 WebUI 配置，预览对照官方文档两种样式：
  - 自定义菜单：灰底圆角胶囊（发送 / 链接 / 蓝色开关带圆点 / 子菜单四宫格）+ 输入框 + 底部工具栏。
  - 指令面板：QQ频道 / 频道私信 / QQ群 / 消息列表页签 + 灰色顶栏手机框，左侧 `/指令`、右侧灰色描述。
- 桌面 GUI 只保留 WebUI 开关、地址和端口；默认 `http://127.0.0.1:3738`，可改成 `0.0.0.0` 供外部访问。
- 官方文档列出的基础字段都能按文档含义自定义。
- 四场景可独立配置，也支持统一配置后一次发送。
- 「确认后发送」，并回显 OlivOS 返回结果（成功/HTTP/错误/response）。
- WebUI 内置帮助文档，字段全部中英对照。

## 注意事项

- 必须使用 **qqGuildV2 官方机器人账号**。其他协议不会出现在 Bot 下拉框里。
- OlivOS 核心需要先补齐菜单/面板接口，否则 GUI 会提示尚未暴露接口。
- 自定义菜单只对 **消息列表单聊** 生效，设置后对所有用户生效，不能按用户区分。
- 指令面板：`channel` / `dm` 只能全局（`target_type=all`）；`c2c` / `group` 才支持指定对象。
- 链接必须 `https://` 开头。
- 官方限制：菜单最多 10 项、子菜单最多 5 项且不可再嵌套、每面板最多 20 元素、每机器人最多 20 个面板。
- 确认发送会 **覆盖** 平台上的完整菜单/面板配置，请先拉取再改。
- **全局骰主**来自 OlivaDiceCore，本插件只读展示，不能在这里改。
- **插件骰主**在 WebUI 全局设置页维护。

## WebUI 使用

OlivOS 插件菜单 → **打开菜单与指令面板** → 把 WebUI 开关打到开启。

默认地址：`http://127.0.0.1:3738`。地址和端口可在开关窗口或 WebUI 全局设置里改；外部访问可填 `0.0.0.0`。

发送到平台后会弹窗显示成功几个、失败几个。插件重载时 WebUI 会先断开，重载完成后若开关开启会立刻重新连上。

页签：

1. **自定义菜单**：编辑底部按钮，右侧是官方单聊快捷菜单预览。
2. **指令面板**：顶部四个场景页签与官方一致，右侧是灰色顶栏手机预览。
3. **指令浏览**：搜索当前草稿里的每一条指令。
4. **全局设置**：开关、只读全局骰主、插件骰主。
5. **帮助文档**：Markdown 渲染。无右侧预览时编辑区铺满。

打开 WebUI 或切换 Bot / 点刷新时，会先拉取平台当前自定义菜单和四个场景的指令面板。

自定义菜单、指令面板页的右侧预览固定在视口里，跟着当前编辑内容变。指令浏览 / 全局设置 / 帮助没有右侧预览，左侧铺满。

建议流程：打开即拉取 → 编辑并看预览 → 确认发送到平台 → 看返回结果。

## 配置说明

数据目录（自动生成）：

- `plugin/data/QQBotMenuPanel/global_config.json`
- `plugin/data/QQBotMenuPanel/<bot_hash>/bot_config.json`

常用字段：

- `global_enable_switch`：插件总开关
- `webui_enable_switch`：本地 WebUI 开关，默认关
- `webui_host` / `webui_port`：默认 `127.0.0.1` / `3738`，可自行修改；`0.0.0.0` 表示监听全部网卡
- `bot_enable_switch`：当前 Bot 开关
- `configured_master_list`：本插件骰主
- `unified_panel_mode`：四场景统一配置
- `menu_draft`：自定义菜单草稿
- `panel_drafts`：按 c2c / group / channel / dm 分开的指令面板草稿

## 安装

1. 确认 OlivOS 的 `qqGuildv2SDK` 已包含自定义菜单 / 指令面板接口。
2. 将 `QQBotMenuPanel` 文件夹或 `.opk` 放入 `YourOlivOSPath/plugin/app`。
3. 重载插件。
4. 用 qqGuildV2 账号登录，打开插件菜单。
