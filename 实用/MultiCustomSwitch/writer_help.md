# MultiCustomSwitch 自定义回复编写帮助

在这里为骰子准备多套回复，再按群选择使用。建议先从 smp 或现有回复复制一份，修改后到测试群切换验证。

## 先选择回复库

- **具体账号**：管理这个骰子能够使用的回复，每个账号都有自己的列表和设置。
- **unity 模板库**：存放共享模板。模板必须先导入具体账号，才能在聊天中切换。
- 首次打开 unity 时，没有模板就会显示空列表。选择具体账号即可看到 default 和 smp。

## 内置回复与序号

- **1/default**：Core 原有的自定义回复。这里的修改与官方 GUI/WebUI、`.str` 共用数据，其他界面刷新后也能看到。想保留原回复时，请先复制再编辑。
- **2/smp**：全默认回复，**只读**，可以复制或导出。骰名使用真实账号名称；暂时取不到名称时显示账号 ID。
- **3 及以上**：自己新建或导入的回复。新序号按当前最大值加 1 分配，不填补中间空缺；同一账号不能重复，不同账号可以使用相同序号。

使用“改名”只改变名称，保留原序号。使用“改序号”后，原来选择这套回复的群和全局设置会自动跟着调整，无需重新切换。

## 新建与复制

1. 在“回复库”选择要保存到的账号或 unity。
2. 点击“新建复制”，选择来源回复库和来源回复。
3. 填写新名称并确认，然后逐项修改回复内容。

可以从 default、smp、当前回复或其他库的任意回复复制。想从全默认内容开始，就选择 smp。
同一回复库不能重名，仅大小写不同也视为重名。

## 从文件或链接导入

**本地文件**：先选择目标回复库，点击“导入 JSON”，选择文件，填写导入后的名称并确认。

**下载链接**：点击“下载 JSON”，填写 HTTP/HTTPS 下载地址及回复名称。链接应直接返回回复 JSON；论坛帖子或网盘分享页面通常不能直接使用。插件会先检查内容格式，再导入。

回复文件需要是“回复键 → 文本”的 JSON 对象，例如：

```json
{
    "strBotName": "青果",
    "strRoll": "{tName} 掷出了 {tRollResult}"
}
```

可以只写需要修改的回复项。**没有写的项使用 smp 的默认文本补齐**，不会混入 default 已经修改过的内容。
空对象 `{}` 也可导入，表示全部使用默认文本。

遇到同名回复时，有三个选择：

- **覆盖**：替换已有内容，保留原序号；已经选用它的群也会使用新内容。需要保留旧版时，请先导出备份。
- **创建为副本**：保留原回复，另存一份；具体账号中的副本会获得新序号。
- **取消导入**：不做修改。

从外部文件、下载链接、其他账号或 unity 导入，都遵循这套规则。
导入到具体账号并覆盖 default，会修改 Core 原有回复；smp 不能覆盖，请选择创建副本或取消。

## 导出与跨库共享

**导出到电脑**：选择回复后点击“导出 JSON”。文件包含这套回复完整的生效文本，可以备份、分享，或导入官方回复管理界面。default 和 smp 也可以导出。

**unity 加载到账号**：先把“回复库”切到目标账号，点击“从其他库导入”，来源选择 unity 和对应模板，填写名称后确认。

**账号回复保存到 unity**：先切到 unity，再用“从其他库导入”选择来源账号及回复。不同账号之间复制也使用这个入口。

跨库导入得到的是一份独立副本。之后修改 unity 模板或来源账号，**不会自动更新**其他账号中的副本；需要更新时，再次导入并选择覆盖。

## 回复编写遵循什么规则

**沿用 OlivaDiceCore 的回复格式和变量规则**。本插件负责选择哪套回复；具体内容怎样替换变量，仍跟随对应的 Core 命令或扩展插件。

先在左侧搜索回复键、内容或说明，选择要修改的项。可以参考它的默认文本和说明，保留必要变量，只调整周围措辞。
不同回复项可用的变量不同，不要把另一项的变量直接照搬过来。单独新增回复键不会自动新增聊天触发指令，需要有对应插件使用这个键。

- `{tName}`、`{tRollResult}` 等变量由对应指令提供，以当前回复项说明为准。
- `|` 分隔随机回复，每次选其中一条。
- `{OR}` 或 `{DEVIDE}` 表示字面上的竖线。
- `{牌堆名}` 可以调用牌堆，需要骰子已加载对应牌堆。
- 编辑框中直接换行即可；手写 JSON 时用 `\n` 表示换行。
- 回复内容必须是字符串，可以为空；不要改成数组、数字或嵌套对象。

例如，在支持 `{tName}` 的回复项中填写：

```text
{tName}，准备好了吗？|轮到你啦，{tName}！
```

需要在 JSON 文件中写两行文本时：

```json
{
    "strRoll": "{tName} 的检定结果：\n{tRollResult}"
}
```

## 图片回复

使用 `[CQ:image,file=图片地址]`，其中 **CQ 必须大写**。例如：

```text
检定成功！[CQ:image,file=https://example.com/success.png]
```

把示例地址换成可直接访问的图片链接。图片能否发送成功还取决于账号接入的消息协议。
这里的回复使用 CQ 码，`[OP:image,...]` 会被当作普通文字。

## 程心自定义解析

回复里可以使用程心的 `【……】` 语法，但需要：

- 已安装并加载 **OlivaDiceJoy** 和 **ChanceCustom（程心自定义）**。
- 在当前账号的官方设置中开启“回复词的程心自定义解析”，即将 `joyEnableCCPK` 设为 `1`。

例如，在回复编辑框中填写：

```text
【发送者昵称】，你的幸运数字是【随机数1>=<100】！
```

满足条件后，切换到的回复同样会执行程心解析，无需在本插件另开一次。未开启时不执行程心语法。
图片仍使用 `[CQ:image,file=...]`；程心函数的具体用法跟随程心自定义的帮助。

## 已修改、未保存与恢复默认

**已修改**：当前内容与所选恢复模块提供的默认文本不同。它可以已经保存，并不代表有未提交的草稿。

**未保存**：编辑框里有尚未保存的改动。点击“保存回复”才会生效；切换回复或回复库时，请先保存或确认放弃。

**恢复默认**：将当前回复项恢复为所选恢复模块的默认文本。具体账号的“恢复模块”与官方界面共用同一设置，保存在 OlivaDice 对应账号目录中。
不知道模块用途时，保持默认即可。清空模块列表后保存，会恢复默认模块列表。

编辑 unity 时，可在“unity 比较基线”选择某个账号，按它的恢复模块判断已修改状态；不选择则与全部默认回复比较。
这只影响比较和“恢复默认”，不会改变 smp 的全默认回复。

## 在群里使用与生效规则

先将回复加载到具体账号，再查看列表并切换，例如：

```text
.mcslist
.mcs3
.mcsshow
```

- 本群切换与开关允许群主、群管理员或当前账号的骰主操作；骰主在群内是普通成员也可使用。`.mcsglobal...` 仍仅允许骰主，所有全局操作只影响当前账号。
- 全局开启后，再读取本群开关；全局或本群关闭时，都恢复使用 1/default 的 Core 原有回复，保留之前的选择。
- 没有单独设置的群继承全局回复，私聊也使用全局回复。首次本群切换或设置开关后，会保存当时的回复与本群开关；以后保留本群自己的选择。
- **本插件不遵循 OlivaDiceCore 的群链**：已关联的各群，回复选择和开关仍独立，不沿群链同步或继承。
- 命令可以不加空格；名称未精确匹配时会给出候选。完整指令和权限请发送 `.mcshelp` 查看。

修改当前正在使用的回复后，后续消息就会使用新内容，不需要重新切换。
从其他界面修改 default，或手工修改文件后，请点击“刷新文件”再继续编辑。
如果文件损坏或缺失，相关群会暂时使用 Core 原有回复；修复后刷新并用 `.mcsshow` 检查。
