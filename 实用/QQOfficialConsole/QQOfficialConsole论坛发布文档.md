## 注意

**先看这四条，能省掉大部分提问：**

1. **没有聊天命令。** 这个插件全部功能都在 OlivOS WebUI 的插件页面里，QQ 里发指令不会触发任何操作。
2. **必须从宿主的侧栏打开。** 直接访问 HTML 文件或静态地址拿不到消息桥，页面会一直加载不出来。插件不另开端口、不启动独立服务、不把机器人 access_token 交给网页。
3. **WebUI 登录者可以借这个页面向机器人能访问的会话发言、执行机器人有权限的管理操作。** 请保护宿主 WebUI 的访问地址和登录凭据，**不要把未受保护的控制台暴露到公网**。
4. **「移出成员」等部分管理接口目前是官方内邀白名单能力。** 没开通的机器人点了会回「无接口权限」（11253），这与插件、与机器人是不是管理员都无关；入口保留是为了白名单开通后即可使用。

## 简介

QQ 官方机器人不是 QQ 客户端：开放平台没有群列表 / 好友列表接口，也没有消息漫游；被动回复有时效和次数，主动发言要群主授权；多账号来回切更是日常。想在电脑上像用 QQ 一样管理这些会话，通常只能靠日志和手写 openid。

**QQOfficialConsole 在 OlivOS WebUI 里做了一个仿 QQ NT 的三栏控制台**：账号切换 + 会话列表 + 聊天窗口 + 会话资料，收到的消息按账号、按会话落本地 SQLite，页面只读这份库。

当前版本提供：

- **多账号**：一个下拉框切换所有已登录的 `qqGuildv2_link` 机器人；账号下拉里带各自的未读和 @我 合计。所有账号始终独立收消息入库，页面开没开、当前看哪个号都不影响。
- **会话自学**：群里 / 单聊来一条消息就自动建会话；冷启动没有事件时用 ＋ 手动填 `group_openid` / `user_openid`。列表按置顶、最后消息时间排序。
- **收发消息**：纯文本、Markdown、原生图文卡片；引用、@成员、@全体（仅群聊）、本地图片、Markdown 插图、永久表情包；失败回固定中文关键词。
- **消息发送策略**：单聊优先流式，群聊优先未过期的被动凭据，池空或不可用时回落主动消息。
- **未读与提醒**：@我 / at全体成员 分开识别、角标与弹窗文案区分，可在设置里分别关掉两类提醒；「屏蔽本群」让消息变灰、不计未读、不提醒，但消息照常收。
- **查找**：本会话的消息记录（关键词、时间范围、只看自己发的、含失败 / 含已撤回）+ 全局搜索（按群名 / 单聊名 / 备注 / openid 定位会话，也能搜消息内容，可按全部 / 群聊 / 单聊 / 消息筛选）。
- **管理员功能**：机器人是群主 / 管理员时才显示——@全体、撤回成员消息、禁言查询与设置、**移出成员（官方内邀接口，未开通会提示无权限）**、入群申请列表与同意 / 拒绝、官方成员列表刷新、主动发言状态。
- **设置与运维**：发送快捷键、首次加载范围、@ 提醒开关、防撤回、左栏使用说明显隐、聊天记录与图片副本保留天数（默认 30 天，0 = 永久），到点自动清理；⚙ 里另有「立即回收磁盘空间」，手动对 SQLite 执行 `VACUUM` 缩小文件（见「数据保存」与常见问题）。
- **失败不丢内容**：发送失败（含平台判定过长、审核拒绝、频控）会撤掉聊天区里的占位气泡，正文 / 卡片字段 / 引用回到输入框，图片下次发送自动重传。
- **撤回可重编辑（仅群聊）**：自己撤回的消息显示「已撤回」和蓝色「重新编辑」，一键把原文放回输入框；设置里可开「防撤回」直接看原文（默认关闭）。
- **机器人真名**：自己消息的作者名和机器人下拉使用官方 `/users/@me` 返回的昵称，不再是笼统的「机器人」。
- **手机可用**：窄屏自动拆成一栏，长按代替右键，虚拟键盘弹起时输入框跟着上移。

## 安装

1. 确认 OlivOS 版本支持 **插件 WebUI**，并且已经登录一个 `qqGuildv2_link` 的 QQ 官方机器人账号。
2. 把 `QQOfficialConsole.opk` 放进 OlivOS 的 `plugin/app/` 目录；使用源码时，把完整的 `QQOfficialConsole/` 文件夹放进同一目录。
3. **重载插件**。
4. 在 OlivOS WebUI 左侧栏的「插件页面」里点开 **QQ 官方机器人控制台**。
5. 冷启动会话列表是空的：让目标群里发一条消息、或让某人给机器人发一条单聊，页面会自动建会话；也可以点左栏 ＋ 手动填 openid。

群里收不到全量消息、发不出主动消息时，需要群主先在 QQ 的机器人设置里放开「获取群内全部消息」与「机器人主动在群聊内发言」；这与插件是否安装无关。

## 使用说明

### 左栏 · 会话列表

- 头像用「群 / 单」色块区分类型；会话行副标题显示完整的 `group_openid` / `user_openid`，资料卡里用全称「群聊：」「单聊：」。
- 主标题优先显示**备注**，其次显示事件里学到的群名 / 昵称，都没有才显示 openid 前 8 位。
- 列表上方两个按钮 **群 / 单**，默认全开：点一下临时收起对应类型的会话，再点恢复。**收起只影响显示和顶部合计**（未读总数、@我 数改为只统计可见会话），消息照常接收、入库、提醒；重新打开页面恢复全开。
- 右键（手机长按）会话：置顶 / 取消置顶、修改备注、**屏蔽本群** / 取消屏蔽、从列表隐藏、复制 ID。置顶用头像下方的小图钉标记。
- **屏蔽 ≠ 隐藏**：屏蔽的群消息照常入库并显示，但整体置灰、不计未读、不计提及、不弹提醒、不把隐藏会话顶回列表；隐藏只是从列表收起，收到新消息会重新出现，两者都**不删库**。
- 点开还没显示群名 / 昵称的会话时会自动补一次：群聊加入原有的群名排队队列（已在队列里不重复入队），单聊没有官方昵称接口，改为跨会话查成员缓存里这个人最近用过的昵称，查到就写上；查不到等之后的事件把昵称带进来，下次点开再查。

### 中栏 · 聊天与发送

| 能力 | 说明 |
| --- | --- |
| 消息类型 | 文本 / Markdown / 图文卡片。卡片要填 HTTPS 跳转链接和 HTTPS 配图地址。 |
| 字数 | QQ 官方机器人没有正文长度上限：输入框只显示「当前 N 字」，不禁用发送；是否超长由平台判定，空正文仍拦。 |
| 引用 | 右键消息可引用；原生引用需要平台引用索引，其余自动转成正文顶部的作者 + 摘要引用块。 |
| @ | ＠ 从本会话成员缓存里点选；群聊另有 @全体（管理员、每群每天 1 次，发送前二次确认）。含 @ 的消息整条走 Markdown。 |
| 图片 | ▧ 从文件选择器上传，分片传给插件落临时目录后随消息发出，发完删除。Markdown 插图插到光标处，可多张。**普通图片不接受网址**。 |
| 表情 | ☺ 永久表情包，按机器人专属 / 全局分开保存，可上传、重命名、删除、插入；发送只消费临时副本。 |
| 快捷键 | 桌面默认 Enter 发送、Ctrl+Enter 换行（可在 ⚙ 改成反过来）；手机只认「发送」按钮，回车只换行。 |
| 撤回 | **仅群聊支持**（官方没有单聊撤回接口，单聊菜单里不显示撤回）：右键消息撤回，自己发的消息 **2 分钟内**可撤回；管理员可撤回成员消息，非管理员会收到「无撤回权限」。撤回后显示「已撤回」+ 蓝色「重新编辑」（仅自己的消息），点击把原文放回输入框；⚙ 可开「防撤回」直接显示原文。 |
| 发送失败 | 自动撤掉聊天区里的占位气泡，正文 / 卡片字段 / 引用留在输入框；已上传图片下次发送时用原始文件重新上传，无需重选。 |
| 消息记录 | ◷ 把右栏切成当前会话的消息记录：按日分组，可筛关键词、时间范围、只看自己发的、含失败、含已撤回；点一条跳到中栏对应气泡。 |
| 历史导航 | 首次只加载最近 30 条；↑ 先回到已加载区顶部，再按一次才加载更早一页；↓ 回到最新。停留在旧消息时收到新消息只提示，不会强行拉回底部。 |

**发送通道（自动选择，不用手选）：**

| 会话 | 优先 | 回落 |
| --- | --- | --- |
| 单聊 | 流式 `POST /v2/users/{openid}/stream_messages` | 卡片 / 富媒体等流式不支持的类型，或失败按错误码判定 → 普通单聊接口 |
| 群聊 | 被动回复（从本群被动池里挑未超次数、最快过期的凭据） | 池空 / 被动不可用 → 主动消息 |

被动凭据有平台时效与次数限制（群聊约 5 分钟 5 次、单聊约 60 分钟 4 次），插件会把每条凭据的已用次数持久化，重启后优先换没用过的，避免 `msg_seq` 重复。流式请求网络超时后结果可能是未知的，**不会自动重发**，以免重复发消息。

### 搜索

- **⌕ 全局搜索**：既按 **群名 / 单聊名 / 备注 / openid** 找会话，也搜消息内容（按最后消息时间倒序扫各会话库，每群最多 20 条、全程上限 100 条）。单聊没有昵称接口，搜索前会先用成员缓存给没名字的单聊补一次显示名；名称完全命中的会话排最前。弹窗里有 **全部 / 群聊 / 单聊 / 消息** 范围筛选（只切换展示，不重复搜索），结果分「会话 N」「消息 N」两组；会话行带头像和完整 ID，消息行带来源会话与时间。
- **点结果即定位**：会话结果直接打开对应群聊 / 单聊，消息结果切到来源会话并定位到那条消息；若该类型被左栏「群 / 单」筛选挡住，会自动恢复显示，并把列表行滚到可见处短暂高亮。勾选「含已隐藏」才会扫隐藏会话。
- **本会话消息记录**：只读当前会话那个库，可以翻全量，不受首次加载 30 条的限制。
- 关键词是普通包含匹配（空格分隔的多个词同时满足），不是正则；两处都**不打平台消息漫游**，只查本地库。

### 右栏 · 资料与管理员操作

群聊资料卡显示显示名、备注、`group_id`、机器人在本群的身份（普通成员 / 管理员 / 群主 / 未知）、成员缓存、被动池剩余次数与过期时间、主动发言状态。

**只有机器人是管理员 / 群主时才渲染**的操作区：

- @全体成员（每群每天 1 次，二次确认）
- 撤回成员消息（2 分钟内）
- 禁言查询 / 设置（可填秒数，0 为解除；消息右键也能直接禁言发送者）
- 移出成员：管理员操作区「移出成员」、点击成员缓存里的成员胶囊、或右键入站消息「移出发送者」三个入口；弹窗可勾选「同时拉黑」，二次确认后调用官方批量移除接口，成功后同步清掉本地成员缓存。**该接口目前是内邀白名单能力**，没开通的机器人会回「无接口权限」（11253），弹窗里也有同样提示；不是插件故障。
- 入群申请：独立面板，自动翻页拉全部申请（守 30 QPM、最多 2000 条），显示昵称、申请时间、来源、验证消息和风险提示，可同意 / 拒绝、拒绝可填理由并拉黑；拉下来的申请进本地库，之后翻看不再打平台
- 官方成员列表刷新

### ⚙ 设置

| 分组 | 内容 |
| --- | --- |
| 展示窗口 | 按条数 / 按天数限制首次加载多少条（默认最近 30 条）；只影响打开会话时的默认范围，搜索仍查全量 |
| @ 提醒 | 「有人 @ 我」「有人 @ 全体成员」两个开关 |
| 界面（全部机器人） | 「左栏使用说明」开关：看熟了可以关掉左栏那块折叠说明面板（默认开） |
| 消息显示（全部机器人） | 「防撤回」开关（默认关）：开启后撤回的消息仍显示原文；关闭时显示「已撤回」和蓝色「重新编辑」 |
| 存储与清理（全部机器人） | 聊天记录保留天数、图片本地保留天数，默认都是 **30**，范围 0–3650，**0 = 永久保留，不自动清理**；底部「立即回收磁盘空间」手动进行分页清理 |

发送快捷键不在 ⚙ 弹窗里改：点 **发送按钮右侧的 ▾ 小三角** 切换「Enter 发送 / Ctrl+Enter 发送」，选择会写进设置保存（Mac 上 Ctrl 和 Cmd 都认）；手机一律点「发送」。

改成 0 时设置页会有橙色警告：长期运行会持续占用磁盘。保存保留天数会**立即按新期限清理一次**，之后后台每小时清一轮；清理后重算未读、提及数、最后消息时间和列表预览，并清掉页面缓存。

缩短聊天记录保留天数（例如 30 → 15）保存后会立刻删掉超期消息，此时点「立即回收磁盘空间」收益最大：空洞是永久的，回收后高水位降到新周期就不再涨回去。顺序必须是**先保存设置、再点回收**；有未保存的改动时按钮会拦住你。

### 手机端

宽度 ≤ 900px 时一次只显示一栏：☰ 回会话列表、ⓘ 进资料、◷ 进消息记录；长按代替右键；图片走系统相册 / 拍照（不强制相机）；输入框随 `visualViewport` 贴到键盘上方。已用浏览器模拟窄视口验证，真机键盘行为仍以实际机型为准，旧版宿主可能遮挡输入区。

## 数据保存

所有数据都在 OlivOS 的数据目录，不进 OPK：

```text
plugin/data/QQOfficialConsole/
├── global.sqlite3                      # 跨账号设置：send_key、last_bot_hash、
│                                       #   poll_interval_ms、保留天数、@ 提醒开关
└── <bot_hash>/
    ├── meta.sqlite3                    # 该号的 chats 会话、群名任务队列、显示范围设置
    └── msg/
        ├── qq_group/<safe_id>.sqlite3  # 群聊：messages / members /
        │                               #   passive_tokens / join_requests
        └── qq_private/<safe_id>.sqlite3# 单聊：同上
plugin/data/image/temp/QQOfficialConsole/       # 发送临时图，发完删
plugin/data/QQOfficialConsole/sent-images/      # 已发图片的本地副本
plugin/data/QQOfficialConsole/inbound-images/   # 代下载收到的图片
plugin/data/image/QQOfficialConsole/emoji/      # 永久表情（分机器人 / 全局）
```

- `<safe_id>` 由 openid 规整得到，特殊字符用 SHA-256 代替；每个 SQLite 用 WAL 模式，**图片二进制不进数据库**。
- 消息按账号写入，不认页面当前选中项；切账号只是换一份 `bot_hash` 读。
- 撤回只把 `recalled` 置 1，隐藏会话只是 `hidden=1`，这两个操作**本身都不删消息行**，也不删 `.sqlite3` 文件；插件没有「一键清空聊天记录」按钮。但到期保留策略会真的删除 `messages` 行（见下方常见问题），需要真正缩小文件请用 ⚙ 里的「立即回收磁盘空间」。
- 收到的图片由插件服务端代下载（带机器人鉴权、仅限 QQ 多媒体域名、同一张只下一次），分片回传前端拼 `blob:` 显示；浏览器不直连图片地址。链接过期（rkey 失效）或非图片内容会显示失败提示。
- **备份**：请按常规备份整个数据目录以及 SQLite 的 WAL 文件。

## 权限与已知限制

**官方机器人不是 NT 客户端**，下面这些是平台限制，不是插件 bug：

| 项目 | 限制 |
| --- | --- |
| 会话列表 | 官方没有群列表 / 好友列表 API，只能靠事件自学或手动加 openid |
| 消息漫游 | 没有；历史消息全部来自本插件启动后自己落库的那部分 |
| 被动回复 | 群聊约 5 分钟 5 次，单聊约 60 分钟 4 次，过期只能用主动消息 |
| 主动发言 | 需要群主在 QQ 里授权；无权限返回「主动无权限」 |
| @全体成员 | 仅群聊、机器人须为管理员、每群每天 1 次 |
| 撤回 | **仅群聊**（单聊无官方撤回接口，菜单不提供，后端直接拒绝）；2 分钟窗口；撤回他人消息需要管理员权限 |
| 群信息 / 成员 / 主动状态接口 | `11253` 等白名单错误码很常见；失败时标记「无接口权限」，保留已有显示名，不反复骚扰平台 |
| 移出成员 | 官方 `batch_remove_members` **目前为内邀白名单能力**：机器人未开通时点确认会回「无接口权限」（11253），插件会进入 SDK 同样的冷却、不反复重试；另需机器人是该群管理员 / 群主 |
| 图文卡片 | 跳转链接和配图地址都必须 HTTPS 且平台可访问；配图由浏览器直连，图站能看到访问者 IP |
| 内容审核 | 实际能否发出、是否审核中由 QQ 平台决定，插件回显「审核中」等关键词 |
| 接入范围 | 只处理 `qqGuildv2_link`；OneBot 和频道 `guild_channel` 不进本控制台 |

**群名排队**：机器人入群时按入群时间 FIFO 入队，官方限额按每机器人 30 次 / 分钟的滑动窗口放行；撞 429 / 频控码退避 120 秒且不限重试次数，网络错误 / 5xx 退避 60 秒，其它错误最多 5 次，11253 等永久错误直接标记失败。队首在冷却期时不会越过它去取后面的群。运行中任务有 300 秒租约，防止并发处理把在途请求抢走。

**群名与昵称来源**：备注 > 事件里见过的名字 / 官方群名 > openid 截断。单聊没有昵称接口，只能靠事件带进来的成员缓存；所以有些会话一开始显示一串 ID，等有消息或缓存命中后会自动补上，也可以直接改备注。

## 常见问题

### 群里说话，列表里没有新会话？

先确认群主已放开「获取群内全部消息」或消息里 @ 了机器人；只有平台实际投递给 OlivOS 的事件才会入库。也可以点 ＋ 手动加 `group_openid` 建会话。

### 发消息提示「主动无权限」「主动频控」？

群聊被动池空了就会回落主动消息，主动发言需要群主授权且受频控。让群里再发一条 @ 机器人的消息补充被动凭据，或检查 QQ 机器人设置里的主动发言开关。

### 会话标题一直是一串 ID？

群名接口有白名单，单聊没有昵称接口。右键「修改备注」是最快的办法；自动补名、排队取群名会在后台继续尝试，取到后显示名会自动更新，不会覆盖备注。

### 「屏蔽」和「从列表隐藏」有什么区别？

屏蔽 = 消息置灰、不计未读 / 提及、不弹提醒，但会话还在列表里、消息照收；隐藏 = 从列表收起，收到新消息会重新出现。两者都不删历史。

### 发送失败后内容去哪了？

不会丢。失败（平台判定过长、审核拒绝、频控、网络异常等）时会撤掉聊天区里那条占位气泡，正文、卡片字段和引用回到输入框，改完再点发送即可；已上传的图片会记住原始文件，下次发送自动重新上传，不用重新选图。只有发送成功才会清空输入框。

### 撤回的消息还能找回来重新发吗？

撤回只对群聊开放，单聊的消息菜单里没有这一项（官方没有 C2C 撤回接口）。群聊里自己发的消息撤回后，气泡显示「已撤回」和蓝色「重新编辑」，点一下原文就回到输入框（卡片会还原标题、描述、链接、配图地址），图片需要重新上传。别人的撤回消息只显示「已撤回」。想直接看撤回原文，可以在 ⚙ →「消息显示（全部机器人）」里打开「防撤回」。

### 聊天记录会存多久？怎么永久保留？

默认聊天记录和图片本地副本都保留 30 天，后台每小时清一次，改设置会立即清一次。⚙ 里把两项都设为 **0** 就是永久保留（完全跳过清理，需要自己管磁盘）。

**会不会清理数据库？会，但只删消息行。** 到期时对每个会话执行 `DELETE FROM messages WHERE created_at < 截止时间`，即把超期的聊天记录从该会话的 `.sqlite3` 里删掉；隐藏会话、已撤回的消息只要超期同样会被删。删完会重算 `meta.sqlite3` 里 `chats` 的未读数、@ 提及数、最后消息时间和列表预览，并清掉页面缓存。

不会删 `.sqlite3` 库文件本身，也不会动 `chats`（会话、备注、置顶、屏蔽）、`members`、`join_requests`、群名任务队列等其它表；会话列表和设置都保留。图片清理删的是 `sent-images/` 与 `inbound-images/` 下超期的图片文件，不碰数据库，消息正文里记录的图片标记/链接也不受影响。

**为什么文件没变小？** SQLite 的 `DELETE` 只是把页挂进空闲列表（freelist），数据库文件不会立刻缩小，空页会被之后的新消息直接复用。默认的 30 天滚动清理是「删一批、写一批」，文件会稳定在约一个保留周期的高水位，不会无限膨胀，所以插件**默认不自动 `VACUUM`**：整库重写要独占文件、峰值约占两倍磁盘、还会让消息读写短暂停顿，每小时跑一次纯属白费。

**要真正缩小文件**：⚙ →「存储与清理」→ **「立即回收磁盘空间」**。二次确认后逐个对 `.sqlite3` 执行 `VACUUM`，完成后显示处理了多少库、回收了多少空间、跳过多少库。它只整理已删除消息留下的空洞，**不删任何聊天记录、会话或设置**；`global.sqlite3` 由常驻连接持有且只有一张设置表，不参与。

**什么时候值得点**：把 30 天改成 15 天并保存（保存会立即删掉超期消息）之后马上点、停用某个机器人 / 退群留下死库之后。平时滚动清理时空页马上被复用，回收量通常接近 0，属正常。执行时需要约等于数据目录大小的空闲空间，被其它程序占用或空间不足的库会跳过（原库完好，可稍后重试），期间机器人收发消息和页面可能短暂停顿，建议在空闲时段操作。

想完全停机处理，也可以备份整个数据目录（含 WAL 文件）后自行执行：

```bash
python - <<'PY'
import sqlite3, pathlib
root = pathlib.Path("plugin/data/QQOfficialConsole")
for p in root.rglob("*.sqlite3"):
    db = sqlite3.connect(str(p), isolation_level=None)
    db.execute("VACUUM")
    db.close()
PY
```

### 点「移出成员」提示「无接口权限」？

正常，这是平台现状：官方 `batch_remove_members`（群成员批量移除）目前是**内邀白名单能力**，未开通的应用调用会返回 11253，插件直接回「无接口权限」，不会假装成功，也不会删本地成员缓存。这与机器人是不是管理员 / 群主无关（管理员身份只是另一道前置校验）。等应用开通白名单后，无需改插件，入口立即可用；冷却期内也不会反复重试接口。

### 图片显示不出来 / 卡片图片打不开？

收到的图片链接带 rkey，过期后无法重新下载；入站图片只允许 QQ 多媒体域名代下载。卡片配图是浏览器直连 HTTPS 地址，需要旧版宿主放行 CSP、且图站可访问。普通消息图片请点 ▧ 从本地上传，不要填网址。

### 多账号时未读角标准吗？

每个账号独立入库，下拉里显示各账号自己的未读 / @我 合计。「群 / 单」筛选只影响当前页面显示和当前账号的合计数字，别的账号、别的页面和实际接收都不受影响。

### 能撤回别人发的消息 / 同意入群申请吗？

要在右栏看到撤回成员消息、禁言、移出成员、入群申请这些操作，机器人必须在那个群里是管理员或群主。非管理员不会渲染这些入口，强行调用桥接口也会被服务端先拦下（`无管理员权限`），再硬发平台也会被拒。**刷新群名不在此列**，普通成员身份一样能点，见「右栏」小节。

另外，「移出成员」走的是官方**内邀白名单**接口：即使机器人是管理员，只要应用没开通该能力，也会回「无接口权限」（11253）；这是平台现状，等开通后功能即可用，不需要改插件。
