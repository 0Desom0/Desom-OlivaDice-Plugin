# MusicSearch 更新日志

- 同一音乐回调按钮运行期间忽略重复点击；失败后可重试，语音成功发送后永久失效并持久化状态。指令发送不限次数。
- 安装包统一更新为 `MusicSearch.opk`，直接覆盖插件目录旧包。

- 按钮简化为“打开链接”和“发送音乐”；QQ 群/私聊可直接回调下载并上传音乐语音。
- 旧宿主不具备 `button_click` 时用指令按钮自动发送 `.点歌语音 歌曲ID`，也支持手动调用。
- 语音下载后按原格式本地上传，支持 MP3/OGG/WAV/SILK；不转码，完成或失败后清理临时文件，保留插件开关检查。

- qqGuildv2 改用 Markdown 展示封面、歌名、歌手、时长和可获取的专辑，配备网易云歌曲跳转按钮。
- 封面读取图片真实宽高填写 Markdown，保留原始比例；读取失败不填猜测尺寸。
- 保留歌手、时长、专辑、歌曲 ID 全部标签；歌手和时长同一行，专辑及 ID 各一行，减少字段间空白。
- 补充网易云歌曲详情请求；详情失败时显示未知时长，Markdown 发送失败时退回文字与链接。
- 插件清单新增 `qqGuildv2_link` 支持，覆盖 QQ 群、QQ 私聊、频道和频道私信；其他平台继续使用 CQ 音乐卡片。

- 支持纯数字输入时按网易云歌曲 `id` 直接查询。
- 修复第三方接口请求兼容性，补充请求头并增加 SSL 兼容处理。
- 音乐卡片现在保留原有展示字段，同时补充 `id`，兼容 LLBot 的 `163` 音乐卡要求。
- 数据目录固定写入 `plugin/data/MusicSearch`，不再误写到 `plugin/tmp`。
- 配置改为按 bot 隔离保存。
- 新增分群配置：一个群一个文件，按群号保存。
- `.点歌 on/off/状态` 默认控制当前群。
- `.点歌 全局 on/off/状态` 控制当前 bot 的全局配置。
- 点歌触发现在同时受“全局开关 / 本群开关 / OlivaDiceCore on-off”三重条件限制。
- 若存在 `OlivaDiceCore`，会遵循其 host/group 的 bot on/off 逻辑。
- 初始化阶段仅创建 bot 级目录与全局 `config.json`，不会预先批量创建群文件。
- 群配置文件只会在该群第一次实际调用时自动创建。
- 保留原有按歌名点歌能力，并继续支持网易云 CQ 音乐卡片发送。
